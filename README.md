# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop built with React and Redux Toolkit. Customers can browse houseplants by category, add them to a shopping cart, and manage their cart before checkout.

## Features

- **Landing page** with a background image, the company name, an About Us section, and a "Get Started" button that opens the product listing.
- **Product listing page** with plants grouped into categories (Air Purifying, Aromatic Fragrant, Insect Repellent, Medicinal, and Low Maintenance). Each plant shows an image, name, description, and price.
- **Add to Cart** button on each plant. The button is disabled once the plant is in the cart.
- **Navigation bar** with links to the home page, the plant listing, and the shopping cart. The cart icon shows the total number of items in the cart.
- **Shopping cart page** that shows each item's image, name, unit price, quantity, and subtotal, plus the total cart amount. Users can increase or decrease quantities, delete items, continue shopping, or check out.

## Tech stack

- React 18 (Vite)
- Redux Toolkit and React Redux for cart state management

## Getting started

```bash
npm install
npm run dev
```
